# Kaemi Avatar

根据你的真实照片建立个人 3D Q 版形象，以认可的基准图持续制作变体，尽量在换衣服、换动作和换状态时保持同一个人。支持 casual、work、training 及自定义状态，后续可独立改变服装、发型、动作和道具。

此公开包不包含任何个人照片、专属人物或宠物预设。

## 安装

将本目录放到 Codex 的 skills 目录，使文件结构为 `~/.codex/skills/kaemi-avatar/SKILL.md`。如果配置了 `CODEX_HOME`，则使用其下的 `skills/kaemi-avatar`。重新打开会话后调用。

## 使用

先上传本人的真实照片，再发送：

> 请用 $kaemi-avatar，根据我上传的照片制作 casual 状态的 Q 版形象，透明背景、站立全身。

### 认可为身份基准

生成满意后明确告诉它：

> 我认可这张作为身份基准。请把本人照片和这张基准图保存在当前工作区的 avatar-private 私人目录，并记录参考位置和当前选择，方便下次继续使用。

### 只改变一项

上传所需服装参考后发送：

> 请用 $kaemi-avatar，基于认可的身份基准，只换成这套 training 服装，保留脸、发型和头身比例，不加其他道具。

需要加入自己的宠物时，另外上传宠物照片并说明姿势。

### 新对话继续使用

提供之前保存的私人目录位置，再发送：

> 请用 $kaemi-avatar，读取我提供的 avatar-private 目录中的本人照片、认可基准和记录，制作 work 状态，只把动作改成挥手。

本机文件需处于当前环境可访问的位置；换电脑时自行复制私人目录或重新上传照片与基准。技能会检查文件能否读取，缺项先请你补充，不会假装记得。已可读取的照片无需重复上传。

固定基准不会被最新生成图自动替换。若要更换，请明确说“将这张设为新的身份基准”。

## 环境

需要支持技能和内置 image_gen 的 Codex 环境；可配合 imagegen skill 使用。默认请求透明 PNG 输出，属于静态图片，不是真实 3D 模型或 ChatGPT Work Pet。图片生成可能消耗所在环境的额度，技能本身不自动生成全套变体。

本工作流帮助降低形象漂移，不能保证每次完全一致；是否像本人仍需你确认。交付时区分视觉检查与文件检查，未验证项目会明确说明。需要本地文件工具才能验证实际保存路径、图片格式和 alpha。

私人参考和生成结果应留在使用者自己的工作区，不要提交到本公开包。若放在公开项目工作区，将私人目录加入该项目的忽略规则。此 skill 不提供云同步或跨会话永久记忆。

## 维护时的最小试用

用本人照片生成一个 casual 候选，认可并保存为基准；再只改一项服装；最后在新对话提供私有参考目录恢复使用。分别检查身份、未改项目和实际交付文件。尚未完成这些图像试用时，不把文字或结构校验称为生成效果测试。
